# BuildBid Security Assessment Capstone

## Overview

BuildBid is a full-stack contractor marketplace web application built with React, Express.js, and SQLite.

This project demonstrates both software development and cybersecurity by identifying, fixing, and verifying common web application security vulnerabilities.

---

## Technologies

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- SQLite

### Security
- Helmet
- Express Rate Limit
- CORS
- OWASP ZAP

---

## Features

- Contractor search
- Featured contractors
- Request estimate page
- Login and Registration pages
- REST API
- SQLite database

---

## Security Improvements

- Added Helmet security headers
- Removed Express framework disclosure
- Restricted CORS policy
- Implemented API rate limiting

---

## Running the Project

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
